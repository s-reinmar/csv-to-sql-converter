# Krok 20 (src/domain/services/SqlGenerator.ts): Implementacja ISqlGenerator – koordynator łączący nagłówki komentarzy, kod z SqlDdlBuilder oraz paczki danych z SqlDmlBuilder w finalny skrypt SQL.

Implementacja interfejsu `ISqlGenerator` w serwisie `SqlGenerator` pełni rolę koordynatora, który łączy różne komponenty odpowiedzialne za generowanie skryptów SQL. Wykorzystuje on nagłówki komentarzy, kod generowany przez `SqlDdlBuilder` oraz paczki danych przetworzone przez `SqlDmlBuilder`, aby stworzyć kompletny i spójny skrypt SQL.

src/domain/services/SqlGenerator.ts
```typescript
import { ISqlGenerator } from '../contracts/ISqlGenerator';
import { ITableSchema } from '../models/TableSchema';
import { ICsvRow } from '../models/CsvRow';
import { SqlDdlBuilder } from './SqlDdlBuilder';
import { SqlDmlBuilder } from './SqlDmlBuilder';

/**
 * Główny koordynator (Orchestrator) implementujący ISqlGenerator.
 * Łączy nagłówki komentarzy, strukturę tabeli (DDL) oraz wiersze danych (DML)
 * w finalny, kompletny skrypt SQL.
 */
export class SqlGenerator implements ISqlGenerator {
    private readonly ddlBuilder: SqlDdlBuilder;
    private readonly dmlBuilder: SqlDmlBuilder;

    constructor(
        ddlBuilder: SqlDdlBuilder = new SqlDdlBuilder(),
        dmlBuilder: SqlDmlBuilder = new SqlDmlBuilder()
    ) {
        this.ddlBuilder = ddlBuilder;
        this.dmlBuilder = dmlBuilder;
    }

    /**
     * Generuje kompletny skrypt SQL dla podanego schematu tabeli oraz wierszy danych.
     * 
     * @param schema Zatwierdzony schemat tabeli
     * @param rows Wiersze sparsowane z pliku CSV
     */
    public generateSql(schema: ITableSchema, rows: ReadonlyArray<ICsvRow>): string {
        const sections: string[] = [];

        // 1. Nagłówek komentarza z metadanymi
        sections.push(this.generateHeaderComment(schema, rows.length));

        // 2. Instrukcja DDL (CREATE TABLE / DROP TABLE)
        const ddl = this.ddlBuilder.generateDdl(schema);
        if (ddl.trim() !== '') {
            sections.push(ddl);
        }

        // 3. Instrukcje DML (INSERT INTO w paczkach)
        if (rows.length > 0) {
            const dml = this.dmlBuilder.generateDml(schema, rows);
            if (dml.trim() !== '') {
                sections.push(dml);
            }
        }

        return sections.join('\n\n') + '\n';
    }

    /**
     * Generuje nagłówek w postaci komentarza SQL z informacjami o konwersji.
     */
    private generateHeaderComment(schema: ITableSchema, rowCount: number): string {
        const timestamp = new Date().toISOString();
        return [
            `-- ==========================================================`,
            `-- Generated by CSV to SQL Converter`,
            `-- Table Name: ${schema.tableName}`,
            `-- Rows Count: ${rowCount}`,
            `-- Generated At: ${timestamp}`,
            `-- ==========================================================`
        ].join('\n');
    }
}
```

## Podsumowanie i weryfikacja (Faza 4, Krok 20)

### [SOLID CHECK]
- Single Responsibility Principle (SRP): Klasa SqlGenerator pełni wyłącznie rolę koordynatora (Orchestratora), delegując budowanie struktur DDL oraz DML do wyspecjalizowanych serwisów, a sama skupia się na składaniu ich w kompletny plik skryptu.
- Dependency Injection & DIP: Klasa przyjmuje w konstruktorze instancje (lub implementacje) SqlDdlBuilder oraz SqlDmlBuilder (z opcjonalnymi wartościami domyślnymi), co ułatwia testowanie jednostkowe.
- Open/Closed Principle (OCP): Dodanie nowych sekcji do generowanego skryptu SQL (np. nagłówków metadanych, nagłówków transakcji BEGIN TRANSACTION / COMMIT) można zrealizować bez naruszania istniejącej logiki budowania tabeli i wierszy.

### [INTERFACE SUMMARY]
- ISqlGenerator – implementacja kontraktu definiującego metodę generateSql(schema: ITableSchema, rows: ReadonlyArray<ICsvRow>): string.   
- Prywatne metody pomocnicze:
- generateHeaderComment(schema: ITableSchema, rowCount: number): string – generuje nagłówek z komentarzem zawierającym metadane generacji (data, nazwa tabeli, liczba zaimportowanych wierszy).

### [REFACTORING ALERT]
- Zastosowano pełne rozdzielenie odpowiedzialności: SqlGenerator zarządza strukturą dokumentu SQL, podczas gdy SqlDdlBuilder i SqlDmlBuilder generują odpowiednio DDL oraz DML.
- Metoda generateHeaderComment dodaje czytelne metadane ułatwiające identyfikację wygenerowanego pliku na dysku.
